Anagame is a fast-paced anagram word game implemented in Python. Players have a limited time to enter valid anagram pairs derived from a seven-letter set generated to ensure a minimum number of possible anagrams. The game supports different letter distributions (uniform or scrabble-based) for generating letters, and uses an AnagramExplorer helper to efficiently compute anagrams and validate guesses.

During gameplay, users can request hints or quit early. After time expires, the game computes detailed statistics such as valid and invalid guesses, accuracy, skill level based on unique words found, and total score weighted by word length. The user-friendly terminal interface displays real-time feedback and a final summary of performance.

This project is ideal for language enthusiasts who enjoy word puzzles and want to improve their vocabulary and anagram-solving skills.
